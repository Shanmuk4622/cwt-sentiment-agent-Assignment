	Notes
* Post-2023 X data is rare: X closed free API access in 2023, so large public corpora mostly end by 2022. The Kaggle Bitcoin 2025–2026 dataset above is the exception and updates bi-monthly.
* Tweet-ID datasets need hydration: Zenodo/IEEE corpora ship IDs only (Twitter redistribution rules). Rebuilding full text requires X API access (paid tier) via tools like twarc or Hydrator, and deleted/protected tweets are lost — e.g. 500M+ of COV19Tweets' 2B IDs were already gone.
* Kaggle access: the dataset download API links responded without a login when tested on 21 Oct 2026; the website download button may prompt for a free Kaggle account.
